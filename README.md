# Bloop Cabinet — личный кабинет с геймификацией

Демо личного кабинета ученика Bloop AI School: уроки-квизы, опыт (XP), уровни, звёзды, серии и награды.
Основной сайт школы: [kids-ai-courses](https://github.com/snowflakee-e/kids-ai-courses).

**Живая версия:** https://snowflakee-e.github.io/kids-ai-cabinet/

Чистые HTML/CSS/JS без сборки. Работает на компьютере, планшете и телефоне. Прогресс хранится в `localStorage` браузера.

## Связь с сайтом школы

Сайт и кабинет живут на одном домене `snowflakee-e.github.io`, поэтому у них общее хранилище браузера (ключ `bloop-cabinet-v1`).

- Вход на сайте («My cabinet») создаёт профиль (имя, возраст) и открывает кабинет — повторно знакомиться не нужно.
- Кнопка «Play now» у курса на сайте открывает кабинет с `?start=<id курса>` — сразу запускается следующий непройденный урок.
- На главной сайта вошедший ребёнок видит свой прогресс: XP, звёзды, уроки, серию, награды.
- В кабинете: ссылка «← School site», подсказка «For your age» по возрасту, кнопка «Log out» (стирает профиль в этом браузере, сервера пока нет).

XP, звёзды и награды считает только кабинет (`js/game.js`); сайт их лишь читает.

## Правила геймификации

| За что | XP |
|---|---|
| Правильный ответ | +10 |
| Серия: каждый ответ начиная с 3-го правильного подряд в уроке | +5 |
| Урок пройден (от 50% правильных) | +20 |
| Идеальный урок (все ответы верные) | +30 |
| Курс завершён (все уроки пройдены) | +100, один раз |

- **Звёзды за урок:** 3 — всё верно, 2 — от 75%, 1 — от 50%, 0 — урок не пройден, нужно повторить.
- **Повторное прохождение** даёт только разницу с лучшим результатом. Нафармить XP одним и тем же уроком нельзя, но улучшить звёзды можно.
- **Уроки открываются по очереди:** следующий доступен после прохождения предыдущего.
- **Уровни:** 9 уровней с названиями (Curious Cadet → AI Wizard), пороги в `js/data.js` → `LEVELS`.
- **Серия дней:** растёт, если заниматься каждый день, сгорает после пропуска.
- **Дневная цель:** 50 XP в день, кольцо прогресса в боковой панели.
- **Серия правильных ответов** продолжается между уроками и сбрасывается на ошибке.
- **10 наград:** First Steps, Sharp Mind, On Fire, Brainiac, Graduate, Flawless, Star Collector, Habit Hero, XP Hunter, AI Champion.

## Структура

```
index.html        разметка кабинета
style.css         стили (компьютер + телефон)
js/bobik.js       маскот Бобик (SVG, 12 состояний)
js/data.js        курсы, вопросы, уровни, правила XP, награды — всё, что меняется без кода
js/game.js        логика геймификации без интерфейса (XP, звёзды, уровни, серии, награды)
js/app.js         интерфейс: экран кабинета, урок-квиз, тосты, конфетти
tests/            тесты логики (node --test)
```

## Как добавить курс или вопросы

Откройте `js/data.js` и добавьте объект в `COURSES`. В каждом вопросе **первый вариант — правильный**: при показе варианты перемешиваются.

## Запуск и тесты

```bash
npx serve .
node --test tests/
```

## Ограничения демо

- Нет сервера: прогресс живёт в одном браузере и не синхронизируется между устройствами.
- Нет настоящего входа. Для продакшена нужен бэкенд (Supabase/Firebase) — логику из `js/game.js` можно перенести как есть.
